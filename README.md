# Online Voting Machine 🗳️

##  Project Description
The **Online Voting Machine** is a web-based application developed to conduct elections in a secure, efficient, and user-friendly manner.  
This system allows registered users to cast their votes online, while the admin can manage candidates and view election results.

The project is built using **PHP** for backend logic, **HTML** for structure, and **CSS** for styling.

---

## 🎯 Objectives
- To provide a simple and secure online voting system  
- To reduce manual effort and paper-based voting  
- To ensure one user can vote only once  
- To display accurate and transparent voting results  

---

## 🛠️ Technologies Used
- **Frontend:** HTML, CSS  
- **Backend:** PHP  
- **Database:** MySQL  
- **Server:** XAMPP / WAMP  

---

##  Features
- User registration and login  
- Secure voting process  
- One vote per user  
- Admin panel for managing candidates  
- Real-time vote counting  
- Result display after voting  

---

##  User Roles
### 1. Admin
- Add / remove candidates  
- View total votes and results  

### 2. Voter
- Login using credentials  
- Cast vote securely  
- Cannot vote more than once
